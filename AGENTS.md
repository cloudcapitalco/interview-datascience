# Working in this repository (for agents)

This repository is a take-home challenge for data science candidates. If you are an
agent helping someone work through it, orient yourself here.

**Start with [`README.md`](README.md).** It covers environment setup (`uv`), where the
data goes (`data/`, provided separately), and links to everything below. Run code through the environment with
`uv run …`.

Key references:

- [`docs/primer.md`](docs/primer.md): what a commitment is and who carries the gap.
- [`docs/challenge.md`](docs/challenge.md): the questions, the limits, what to submit.
- [`docs/data_dictionary.md`](docs/data_dictionary.md): every column in the two data files.
- [`docs/understanding_debt.md`](docs/understanding_debt.md) and [`docs/understanding_ledger.md`](docs/understanding_ledger.md): what the work is evaluated on. Read these.
- [`notebooks/starter.ipynb`](notebooks/starter.ipynb): loads the data.
